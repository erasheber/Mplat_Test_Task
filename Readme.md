# Тестовое задание – Платежная форма

## Описание

Full-stack приложение для приёма, хранения и отображения платёжных данных.

⚠ Обработка реальных денежных операций не выполняется.  
Проект реализован строго по предоставленному ТЗ.

---

## Технологии

### Backend
- .NET 8
- FastEndpoints
- EF Core 8
- PostgreSQL
- Clean Architecture
- xUnit + Moq + FluentAssertions

### Frontend
- Vue 3 (JavaScript)
- Vite
- Axios

### Инфраструктура
- Docker
- Docker Compose

---

## Запуск

В корне проекта выполнить:

docker compose up --build

После запуска доступны:

Frontend:
http://localhost:5173

Swagger:
http://localhost:5000/swagger

---

## Защита API

Используется API Key:

X-Api-Key: dev-secret-key

Frontend добавляет заголовок автоматически.

---

## Функциональность

- Создание платежа (валидация на клиенте и сервере)
- История платежей (сортировка, пагинация)
- Статистика:
  - Общая сумма
  - Количество платежей
  - Агрегация по дням

---

## Часовые пояса

- Все даты в БД хранятся в UTC
- Статистика по дням рассчитывается с учётом заголовка X-Timezone-Offset

---

## Важно (агрегация валют)

Суммы разных валют агрегируются совместно, так как это указано в ТЗ.

В реальной финансовой системе такое поведение некорректно.  
Production-реализация потребовала бы:
- Агрегацию по валютам
- Либо конвертацию в базовую валюту через FX-курсы
